### Slide 5: AI Architecture

#### 🖥️ Visual Slide Layout
- **Header:** AI Architecture — *10-Agent Multi-Agent Pipeline*
- **Architecture Diagram:**
  ```
  [Raw User Expenses]
          │
          ▼
  [1. Categorizer Agent] ──▶ Auto-classifies transactions into categories
          │
  ┌───────┼──────────────┐  (Parallel Execution via Promise.allSettled)
  ▼       ▼              ▼
  [2. Pattern] [3. Savings] [4. Budget]
  Analyzer     Advisor      Planner
  Agent        Agent        Agent
  └───────┬──────────────┘
          ▼
  [5. Orchestrator Synthesis Agent] ──▶ Executive Financial Summary & AI Report
  ```
- **Specialist Agents Highlight:**
  - 🔮 *Prediction Agent* • 📄 *Monthly Report Agent* • ❤️ *Health Score Agent* • 💬 *Finance Chat Agent* • 🐷 *Savings Goal Agent*
- **Key Design Choice:** Failure-isolated architecture — if one agent fails, structured fallbacks ensure the user receives partial analysis without system crashes.

#### 🎙️ Speaker Notes
> "Under the hood, SpendSense AI is driven by a sophisticated multi-agent orchestration architecture built on Groq's Llama 3.3 70B model.
> 
> Rather than relying on a single monolith prompt, we distribute workload across 10 specialized agents. When a user requests analysis, Stage 1 categorizes transactions. Stages 2, 3, and 4 run in parallel — analyzing velocity trends, generating cost-reduction advice, and creating a 50/30/20 budget allocation. Finally, Stage 5 synthesizes all agent outputs into a unified executive summary.
> 
> Crucially, our architecture features complete failure isolation: if any sub-agent fails, predefined fallbacks engage so the user experience is never interrupted."

### Slide 7: System Workflow

#### 🖥️ Visual Slide Layout
- **Header:** Data & Event Workflow — *From Transaction to Intelligence*
- **Step-by-Step Flow (Horizontal Timeline):**
  1. 💳 **Expense Entry:** User adds an expense or imports transactions. Raw input is sanitized using regex escaping to prevent security vulnerabilities.
  2. ⚡ **Event-Driven Triggers:** Async background workers evaluate transaction amount (≥₹5,000), duplicate status, and budget utilization (80%/100%).
  3. 🔔 **Smart Alerts:** If a threshold is crossed, a deduplicated notification is written to MongoDB and dispatched to the frontend via 30s background polling.
  4. 🤖 **AI Pipeline Execution:** The Orchestrator aggregates expense history, executes parallel LLM prompts via Groq, and updates the AI Report store.
  5. 📊 **Dashboard Synthesis:** Recharts components and UI stat cards re-render with fresh predictions, category breakdowns, and health scores.

#### 🎙️ Speaker Notes
> "Let's trace how data flows through SpendSense AI.
> 
> When a user logs an expense, the system immediately sanitizes inputs and triggers background checks. Is this a duplicate? Is it over ₹5,000? Does this cross 80% of the monthly budget? If any condition is met, a notification is persisted and pushed via toast alerts.
> 
> Simultaneously, the transaction feeds into our AI pipeline. Groq agents analyze the shift in spending velocity, update predictive models, and refresh the user's dashboard visualizations seamlessly."
